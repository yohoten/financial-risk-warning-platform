防前视偏差

防过拟合

快速开始

演示模式 3 分钟跑通全链路，无需任何数据权限

bash — Streamlit 快速原型 
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 数据 + 特征（演示数据：240 家公司 × 10 年）
python -m etl.run_pipeline

# 训练 + 评估 + 解释
python -m models.train --trials 30
python -m models.evaluate
python -m models.shap_analysis

# 启动 → http://localhost:8501
streamlit run streamlit_app/streamlit_app.py
⚠️ 已有真实数据时勿跑 make all：演示数据生成器会拒绝覆盖 CSMAR 真实文件；真实链路从 make pipeline 起。
bash — Vue 3 SPA 生产化前端 
# 1) 启动后端服务层
uvicorn api.main:app --port 8000

# 2) 前端依赖 + 开发模式 → http://localhost:5173
cd web && npm install && npm run dev

# 3) 生产构建（产物在 web/dist/）
npm run build

# 可选：LLM 智能研判
# .env 配置 LLM_BASE_URL / LLM_API_KEY / LLM_MODEL
# （DeepSeek / OpenAI / vLLM 等 OpenAI 兼容端点）
Vite 开发期自动代理 /predict /explain /finance /alerts /analyze 等前缀到 :8000，前后端零 CORS 配置。
