## 二、ST 标签：官方表受阻与代理方案

### 2.1 官方表为什么没下到

CSMAR 镜像站（`https://csmarlsdx.keyanwangshuju.com/`）当前登录账号为“NU本部”。搜索“特别处理”可以检索到《特殊处理变动文件》，但进入以下两个库都显示 **“暂无数据”**：

- 股票市场系列 → 特殊处理与特别转让（databaseId=60）
- 公司研究系列 → 经营困境 / 风险监测（databaseId=192&serid=3）

判断：**账号没有该库的数据权限**，不是检索方式错误。需要机构管理员开通，或换有权限的账号手动导出。

### 2.2 代理标签怎么构造

脚本：`scripts/build_st_labels_proxy.py`

1. 解析 `basic_info.csv` 物理行，保留 `证券代码` 为 6 位数字、`EndDate` 为 `YYYY-MM-DD` 的年度记录；
2. 只保留沪深 A 股前缀：`000/001/002/003/300/301/600/601/603/605/688`，剔除 B 股（200/900）与北交所（8xx/920）；
3. 对每个公司-年，看年末 `ShortName` 是否以 `ST` 或 `*ST` 开头，是则记 `is_st=1`；
4. 把连续为 1 的年份合并为事件段，生成 `data/incoming/csmar/ST_events_proxy.csv`；
5. `etl.csmar_import.build_labels` 以财务主表公司-年为全集，显式写 0/1，并按 [实施年, 撤销年] 回挂。

### 2.3 代理结果

| 指标 | 数值 |
|---|---:|
| A 股年度记录 | 70,838 条 / 5,513 家公司 / 2001–2025 |
| 代理事件段 | 1,263 段 / 933 家公司 |
| `labels_st.csv` | 48,290 个公司-年 / 2013–2025 |
| 正样本 | 1,352（**2.80%**） |
| 重复主键 | 0 |
| 年度正样本率 | 2013 2.03% → 2020 5.01% → 2023 2.06% → 2025 3.34% |

### 2.4 代理标签的局限（论文必须写）

- **状态快照，不是公告事件**：只反映年末证券简称，年内实施又撤销的 ST 会漏标；
- **实施日期不精确**：以“首次出现 ST 简称的年度”代替交易所实施公告日；
- **2026 年缺失**：基本信息表最新到 2025-12-31，2024 特征年需要的 2026 标签无法生成；
- **口径混合**：ST 与 *ST 未区分，退市整理期未单独处理；
- **正样本率偏低**：2.80% 低于部分文献的 5%–10%，可能低估风险样本，影响召回率与 PR-AUC 的可比性。

> 代理标签只用于**解锁训练与工程验证**。论文最终结果应使用官方《特别处理表》重跑；代理版保留在 `data/incoming/csmar/ST_events_proxy.csv` 作为审计痕迹。

## 三、全链路实测

### 3.1 数据流水线

```bash
python -m scripts.build_st_labels_proxy --write
python -m etl.csmar_import --step labels --write
python -m etl.run_pipeline
```

| 环节 | 结果 |
|---|---|
| 清洗面板 | 52,203 行 × 65 列（5,643 家公司，2013–2025） |
| 缺失插补 | 12.58% → 5.41% |
| 特征面板 | **33,191 行 × 73 维**（2015–2023，正样本率 3.41%） |
| 特征筛选 | 73 → 49（IV）→ 45（共线）→ 43（PSI）→ **28 维**（RF-importance） |
| 建模输入表 | 33,191 行 × 37 列 |
| 训练 / 验证 / 测试 | 28,396 / 4,795 / 0 行 |
| 流水线耗时 | 约 20 秒 |

### 3.2 五模型验证集结果（2023，代理标签，未调参）

| 模型 | AUC | PR-AUC | KS | F1 | Precision | Recall | Brier |
|---|---:|---:|---:|---:|---:|---:|---:|
| LogisticRegression | 0.8699 | 0.2105 | 0.6022 | 0.2427 | 0.1443 | 0.7622 | 0.1560 |
| RandomForest | **0.8822** | 0.2637 | 0.6316 | **0.2500** | 0.1484 | 0.7927 | 0.0602 |

- XGBoost 决策阈值：0.3354（Youden，在 2023 验证集冻结）；
- 风险分级：高风险 ≥ 0.3354，中风险 ≥ 0.1677；
- 测试集 0 行，**没有 2024 指标**；以上仅为代理标签下的初步结果，不能作为论文最终结论。

### 3.3 已确认的工程修复

1. `build_labels` 旧实现只输出正样本、忽略撤销日期，导致 `add_features` 的 `notna()` 丢掉全部负样本；已改为输出完整 0/1 全集、按 [实施年, 撤销年] 回挂。
2. 新增 A 股前缀过滤，剔除 B 股/北交所，标签主键重复为 0。
3. `validate_raw_data.py` 的标签覆盖检查改为按 **T+2** 对齐，并只统计 A 股，避免把 B 股算成标签缺口。

## 五、复现命令

```bash
# 1. 生成代理 ST 事件与标签
python -m scripts.build_st_labels_proxy --write

# 2. 由事件表生成 0/1 标签
python -m etl.csmar_import --step labels --write

# 3. 清洗 + 特征 + 筛选 + 建模输入表
python -m etl.run_pipeline

# 4. 质量体检（严格门仍会报 2024 测试标签缺口）
python -m scripts.validate_raw_data

# 5. 五模型训练（快速验证，不调参）
.venv\Scripts\python.exe -m models.train --no-optuna --no-cv
```

> Windows 下请使用项目 `.venv\Scripts\python.exe`，系统 Python 未安装 xgboost/lightgbm/catboost。
