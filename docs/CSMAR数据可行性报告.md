### 3.5 ST 代理标签：口径、数量与局限

**为什么用代理**：CSMAR 镜像站能检索到《特殊处理变动文件》（股票市场系列 → 特殊处理与特别转让；
公司研究系列 → 经营困境/风险监测），但当前机构账号进入后两个库都显示“暂无数据”，即无该库数据权限。
为不阻断训练，先从已到位的《上市公司基本信息年度表》构造代理。

**构造方法**（`scripts/build_st_labels_proxy.py`）：

1. 解析 `basic_info.csv` 的物理行，保留 `证券代码` 为 6 位数字、`EndDate` 为 `YYYY-MM-DD` 的年度记录；
2. 只保留 A 股前缀（000/001/002/003/300/301/600/601/603/605/688），剔除 B 股（200/900）与北交所（8xx/920）；
3. 对每个公司-年，看年末 `ShortName` 是否以 `ST` 或 `*ST` 开头，是则 `is_st=1`；
4. 把连续为 1 的年份合并为事件段，`start_year` 为首次实施年、`end_year` 为最后一年，
   生成 `data/incoming/csmar/ST_events_proxy.csv`；
5. `build_labels` 以财务主表的公司-年为全集，显式写 0/1，并按 [实施年, 撤销年] 区间回挂。

**结果**：

| 指标 | 数值 |
|------|------|
| 解析 A 股年度记录 | 70,838 条 / 5,513 家公司 / 2001–2025 |
| 代理事件段 | 1,263 段 / 933 家公司 |
| `labels_st.csv` | 48,290 个公司-年，2013–2025 |
| 正样本 | 1,352（**2.80%**） |
| 年度正样本率 | 2013 2.03% → 2020 5.01% → 2023 2.06% → 2025 3.34% |
| 重复主键 | 0 |

**局限（论文必须写明）**：

- **状态快照，不是公告事件**：只反映年末简称，年内实施又撤销的 ST 会漏标；
- **实施日期不精确**：以“首次出现 ST 简称的年度”代替交易所实施公告日；
- **2026 年缺失**：基本信息表最新到 2025-12-31，2024 特征年需要的 2026 标签无法生成；
- **口径混合**：ST 与 *ST 未区分，退市整理期未单独处理；
- **代理正样本率偏低**：2.80% 低于部分文献的 5%–10%，可能低估风险样本，影响召回率与 PR-AUC 的可比性。

**替换路径**：拿到官方《特别处理表》后，覆盖 `data/raw/ST_events.csv`，重跑
`python -m etl.csmar_import --step labels --write` 与 `python -m etl.run_pipeline`，
特征与模型代码无需改动；代理事件表保留在 `data/incoming/csmar/ST_events_proxy.csv` 作为审计痕迹。

## 七、已知问题与处理

| 问题 | 处理方式 |
|------|---------|
| 现金流量表为 XLSX 且 `dimension` 只声明 1 列 | `scripts/convert_csmar_xlsx.py` 中 `reset_dimensions()` 后流式读取 |
| 该 XLSX 表头占 3 行（代码/中文名/单位） | 跳过 2 行、以第 1 行为字段名 |
| 审计意见表 222 行字段内逗号未转义（ragged） | 用 `csv` 逐行容错解析，坏行跳过并计数 |
| 十大股东单文件 100 万行上限 | 三批合并，按 `Stkcd + Reptdt` 去重 |
| 审计机构误用签字会计师字段 | 改用 `Dadtunit`（境内所）/`Iadtunit`，四大占比由 0% 修正为 6.90% |
| 行业代码在部分年份缺失 | 按公司前后向填充，仍缺失记为 `UNKNOWN` |
| 2013 年样本偏少 | 属正常（当年上市公司数量少），论文可做 2015 年起样本 |
| 2025 年年报不完整 | 建模窗口仍为 2015–2024，2025 仅用于最新一期预警 |
| 演示数据残留 | 已迁移至 `data/demo_raw/`；宏观演示值改名为 `macro_industry.demo.csv`，**不参与真实建模** |
| 官方 ST 表无权限 | 先用 `scripts/build_st_labels_proxy.py` 从基本信息简称生成代理；官方表到位后覆盖 `ST_events.csv` 并重跑 labels |
| 代理标签漏标年内撤销 | 代理按年末简称判断；论文需把“ST 代理口径”写入变量定义与局限 |
| 2024 测试集为空 | 需要 2026 年 ST 事件；当前训练/验证（2015–2023）不受影响，测试指标暂缺 |
