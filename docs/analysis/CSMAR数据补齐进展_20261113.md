## 2. `SPT_Company.csv` 为什么不能用

文件：`CSMAR_download/pakage/公司文件222913114(仅供NU使用)/SPT_Company.csv`

实际结构：

- 526 行 × 24 列；
- 字段为 `Stkcd, Stknme, Listdt, Conme, Indcd, Statco, Statdt, ...`，是公司主数据/当前状态；
- `Statco`：A=382、D=140、N=3、T=1；
- 177 家公司简称含 `ST`/`*ST`；
- **没有** `实施日期`、`撤销日期`、`特别处理类型`，也没有逐次状态变动记录；
- 只有 526 家公司，远少于财务主表的 5,000+ 家 A 股，不能作为全样本标签全集。

它可以用于：核对公司代码、简称、上市日期、当前状态；不能用于：构造历史 ST 标签、替换官方 ST 事件表、评估 2024/2026 锁箱。

## 3. P0：官方 ST 事件表

### 3.1 来源与字段

- 路径：数据中心 → 单表查询 → 股票市场系列 → 特殊处理与特别转让 → **特殊处理变动文件**；
- 物理表：`SPT_Trdchg`；
- 导出：全部 A 股，1998-04-28 至 2026-11-13，CSV；
- 字段：`Stkcd, Stknmebc, Stknmeac, Chgtype, Annoudt, Execudt`。

`Chgtype` 是**变动前/变动后**两个状态字符：

| 字符 | 含义 |
|---|---|
| A | 正常上市 |
| B | ST |
| D | *ST |
| C | PT |
| S | 暂停上市 |
| T | 退市整理期 |
| X | 终止上市 |

例如 `AB` = 正常 → ST，`BA` = ST → 正常，`AD` = 正常 → *ST。

### 3.2 处理结果

原始 4,285 行，剔除 B 股/非 A 股代码后 3,999 行状态变动；按“进入 B/D 开始、离开 B/D 结束”压缩：

- **1,539 段** ST/*ST 区间；
- **1,103 家公司**；
- 区间起点 1998 年，开放区间截至 2026 年导出日；
- 47 行变动前/后简称为空，但证券代码、变动类型、日期完整，不影响区间。

输出：

- `data/incoming/csmar/ST_events_official.csv`：1,539 段事件；
- `data/incoming/csmar/labels_st_official.csv`：2013–2025 共 48,290 个公司-年，正样本 **1,897（3.93%）**；
- `data/incoming/csmar/st_official_summary.json`：年度分布与汇总。

### 3.3 与代理标签的差异

当前代理标签 `data/raw/labels_st.csv` 是“基本信息年度表年末简称是否以 ST/*ST 开头”，正样本 1,352（2.80%）。与官方标签在 48,290 个重叠公司-年上：

- 一致率 **98.65%**；
- 代理 0 / 官方 1：**598** 个（代理漏标，典型是年内实施、年内撤销，或简称未及时反映）；
- 代理 1 / 官方 0：**53** 个（代理误标，典型是简称沿用/快照口径差异）。

这验证了官方表的必要性，也说明不能把 `SPT_Company` 的当前简称当作历史标签。

### 3.4 为什么还不能评估 2024 锁箱

`etl/feature_engineering.py::sync_label` 将标签年份减去 `LABEL_HORIZON=2` 后挂到特征年份：

```text
2022 特征 ← 2024 标签
2023 特征 ← 2025 标签
2024 特征 ← 2026 标签
```

官方事件表有 2026 年记录，但 `data/raw/csmar_financial.csv` 只有 2013–2025 年公司-年键，因此 `labels_st_official.csv` 只能到 2025。要评估 2024 锁箱，必须补到 2026 年财务主表键（或明确改变标签口径）；不能用 2025 标签冒充 2026 标签。

## 7. 单表查询的标准操作（本次验证）

1. 数据中心 → 单表查询 → 顶部搜索关键词（如“违规处罚”“治理结构”“财务指标分析”）；
2. 点结果行进入表组，左侧树选择具体物理表；
3. 设置时间区间（建议 2013-01-01 至 2026-12-31）与“全部 A 股”；
4. 点“全选”选字段；点“预览数据”核对列名/行数；
5. **先关闭预览弹窗**，再选“CSV 格式（*.csv）”，点“下载数据”；
6. 在下载页点“本地保存数据”，浏览器会保存 zip 到下载目录；把 zip 放到 `CSMAR_download/pakage/`；
7. 解压后不要改列名/单位；对含未转义换行的表，用 `scripts/clean_ragged_csv.py` 或 `scripts/clean_cg_ybasic.py` 清洗；
8. 在 `data/incoming/csmar/download_log.md` 记录表名、筛选、年份、行数、下载时间、备注。
