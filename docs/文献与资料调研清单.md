## 一、调研设计

### 1.1 检索策略

| 项 | 内容 |
|----|------|
| 中文数据库 | CNKI、万方、维普；重点期刊《经济研究》《会计研究》《金融研究》《数量经济技术经济研究》 |
| 英文数据库 | Web of Science、ScienceDirect、JSTOR、SSRN、arXiv、NeurIPS/ICML/KDD Proceedings |
| 检索式（英文） | `("financial distress" OR bankruptcy OR "credit risk") AND ("machine learning" OR XGBoost OR "gradient boosting")`；`(SHAP OR "explainable AI" OR XAI) AND ("credit scoring" OR "financial risk")` |
| 检索式（中文） | `财务困境 + 预警`、`财务危机 + 机器学习`、`可解释性 + 信用风险`、`ESG + 财务绩效` |
| 时间范围 | 经典理论不限年份（1966-1984）；方法类 2015-2026；中文文献 1999-2026 |
| 筛选标准 | ① 提出或验证预警模型；② 报告 AUC/KS 等可比较指标；③ 可解释性与非财务特征优先；④ 剔除纯营销/无实证支撑文章 |

### 1.2 文献分层（四级结构）

```
L1 理论基础（6 篇）
├── 经典统计模型：Altman(1968) Z-Score、Beaver(1966)、Ohlson(1980) O-Score、Zmijewski(1984)
└── 市场基础模型：Merton(1974) KMV 思想

L2 方法论演进（8 篇）
├── 集成学习：Chen & Guestrin(2016) XGBoost、Grinsztajn et al.(2022) 表格数据之争
├── 深度学习对照：Hosaka(2019)、Barboza et al.(2017)
└── 超参优化：Akiba et al.(2019) Optuna

L3 可解释性（4 篇）
├── Lundberg & Lee(2017) SHAP 原始论文
├── Lundberg et al.(2020) TreeSHAP 全局理解
├── Davis et al.(2023) 消费信贷可解释模型
└── 中文：王圣洁(2022) 基于 XGBoost 的财务造假识别

L4 非财务特征（6 篇）
├── 文本情感：Shen & Zhang(2024) FinBERT 金融情感
├── 治理与 ESG：Berg et al.(2022)、Christensen et al.(2022)、李季鹏(2024)
└── 数字化转型：金星晔等(2024) 大语言模型测度
```

3. CSMAR 具体字段手册（D02）为机构内部文档，论文中只能引用公开帮助页；
4. 缺少"中国制造业 ST 预测"的最新大规模基准数据集，因此自建样本。

## 三、使用方法

### 3.1 一键获取

```bash
# 在 docs/ 目录下执行
pip install requests tqdm

python batch_download_resources.py --list                       # 先看清单（不联网）
python batch_download_resources.py --type paper --dry-run       # 预览将下载哪些
python batch_download_resources.py --type paper                 # 下载开放获取 PDF
python batch_download_resources.py --type repo                  # 克隆参考实现
python batch_download_resources.py --only-ids P13 P14 P27 P28   # 只取关键几篇
```

### 3.2 归档规范

```
docs/downloads/
├── papers/                  # 命名：{ID}_{标题截断}.pdf，例如 P13_A Unified Approach to Interpreting.pdf
├── repos/                   # 浅克隆（--depth 1），仅用于代码参考，不纳入本项目仓库
├── manual_download_list.md  # 需人工获取的清单（自动生成）
└── download_log.txt         # 完整日志（自动生成）
```

**引用规范**：正文引用以上资源时，统一使用 `resources_catalog.csv` 的 `id` 作为内部索引，
正式参考文献按 GB/T 7714-2015（中文）/ APA 7th（英文）排版，格式提示见
[`desgin/开题报告_文献综述章节写作蓝图.md`](./desgin/开题报告_文献综述章节写作蓝图.md) 附录三。

### 3.3 合规边界

- 仅自动下载**开放获取**（arXiv / NeurIPS / PMC / 机构 OA）PDF；
- 付费文献通过学校图书馆或 SSRN 预印本获取，脚本不绕过任何付费墙；
- 中文文献通过校园网 CNKI 正常订阅渠道下载；
- `repos/` 中的第三方代码仅作方法论参考，不直接复制进本项目（许可证可能不兼容）。
