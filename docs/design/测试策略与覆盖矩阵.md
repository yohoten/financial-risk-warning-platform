## 1. 测试分层策略

| 层 | 目标 | 运行代价 | 当前实现 |
|---|---|:---:|---|
| **L1 单元测试** | 纯函数与统计量的数学正确性 | 秒级 | ✅ 主体（`tests/`） |
| **L2 契约测试** | API 请求/响应与权限点的一致性 | 秒级 | ✅ `test_api.py` / `test_auth.py` |
| **L3 集成测试** | 多模块串联（数据 → 特征 → 面板） | 分钟级 | ✅ `test_io_and_pipeline.py` / `test_production.py` / `test_pull_closure.py` |
| **L4 端到端** | 真实数据 + 真实模型的完整链路 | 小时级 | ❌ 未纳入 CI（`docker/entrypoint.sh` 中有自检脚本） |
| **L5 契约快照** | OpenAPI / 证据冻结清单 diff | 秒级 | ❌ 建议新增（P2-4 / P2-6） |

**分层原则**

1. L1/L2 **不得**依赖模型产物与真实数据——使用 `tests/conftest.py` 的**内存面板夹具**（不写盘、不依赖模型），保证 CI 在无数据环境下可跑；
2. L3 允许依赖 `data/raw/` 的真实契约数据，但必须在数据缺失时**自动跳过**而非失败；
3. L4 仅在发布前与答辩前执行，不进 CI 的必过路径。

## 3. 未覆盖风险面（缺口清单）

> 以下模块已上线并可被外部调用，但**没有对应测试文件**，属 P2-5 的补齐范围。

| 优先级 | 模块 | 端点 / 能力 | 风险 | 建议测试 |
|:---:|---|---|---|---|
| **高** | `api/agent/` | Agent 循环、工具注册、审批 | LLM 输出不可控，可能触发越权工具调用 | 工具白名单越权用例；`MAX_STEPS` / `MAX_TOOL_RESULT_CHARS` 截断边界；审批流程 |
| **高** | `api/mcp/` | MCP 客户端、服务端、工具同步 | 外部 URL 可配置 → SSRF 风险；`auth_header` 落库 | URL 白名单校验；凭据不落盘断言；`/mcp` 端点的调用隔离 |
| **中** | `api/routers/plugins.py` | 插件工具 CRUD 与导入导出 | 插件代码可执行 → 注入面 | 插件名白名单字符校验；导入导出往返一致性 |
| **中** | `api/routers/skills.py` | 技能 CRUD | 技能内容进入 LLM prompt | 长度上限与提示词注入用例 |
| **中** | `api/routers/tables.py` | 表格单元格写入与入库 | 写入路径可触达业务库 | 单元格类型与范围校验；`/ingest` 幂等 |
| **中** | `api/routers/attachments.py` + `api/services/reading.py` | 附件上传 / 视觉识别 | 文件类型与大小未在测试中约束 | MIME 嗅探与大小上限；sha256 去重；`/read` 的 `dry_run` 语义 |
| **中** | `api/worker/scheduler.py` | 定时拉取任务调度 | 任务状态机异常导致重复执行 | 任务状态迁移（PENDING→RUNNING→SUCCESS/FAILED/RETRYING） |
| **中** | SSE `/events/stream` | 实时事件流 | 长连接未验证 | 连接与断开、事件顺序、鉴权后仍不可订阅 |
| **低** | `api/llm/` | LLM 客户端重试与错误映射 | `LlmException.retryable()` 边界 | 408/429/5xx/网络错误分别判重试 |
| **低** | `api/services/reading.py` | 文档解析 | 解析失败降级 | 异常输入不崩溃 |

## 5. CI 闸门现状与增强建议

### 5.1 现状（`.github/workflows/ci.yml`）

| Job | 内容 | 条件 |
|---|---|---|
| `test` | `pip install -r requirements.txt` → `python -m pytest -q` | 总是 |
| `test`（附加） | `python scripts/build_homepage.py --check` | 仅当 `models/artifacts/evaluation_metrics.json` 存在 |
| `data-gate` | `python -m scripts.check_data_readiness --quiet` | 仅当 `data/raw/csmar_financial.csv` 存在 |

### 5.2 增强建议（P2-4，**本轮不修改 CI**）

| 闸门 | 命令 | 目的 | 优先级 |
|---|---|---|:---:|
| **Lint** | `ruff check .`（`pyproject.toml` 已有配置） | 统一风格、捕获未使用导入 | 高 |
| **前端构建** | `cd web && npm ci && npm run build` | 保证 SPA 可编译（`web/dist` 不入库，当前 CI 完全不校验前端） | 高 |
| **文档链接检查** | `python scripts/check_doc_links.py` | 防止本轮修复的失效链接再次出现 | 高 |
| **契约快照 diff** | 导出 OpenAPI 与归档版本 diff | 端点变更可被审阅 | 中 |
| **证据冻结校验** | `python scripts/check_evidence_freeze.py` | 保证文档数字与产物一致（ADR-010） | 中 |
| **类型检查** | `mypy` / `pyright`（可选） | `api/` 层类型标注较完整 | 低 |

### 5.3 本地复现

```bash
python -m pytest -q                 # 全量（115）
python -m pytest tests/test_auth.py -q
python -m pytest -q -k "not api"    # 跳过需要模型的用例
```

## 6. 测试数据约定

| 约定 | 说明 |
|---|---|
| 内存夹具 | `tests/conftest.py` 提供内存面板，**不写盘、不依赖模型产物** |
| 模型缺失自动跳过 | `test_api.py` 在无模型产物时自动 skip，不失败 |
| 数据缺失自动跳过 | 需要 `data/raw/` 的用例在数据缺失时 skip |
| 不 mock 领域层 | L3 用例使用真实 ETL 代码，仅替换 IO 落盘位置 |
| 随机种子固定 | `config/settings.py` 的 `RANDOM_SEED` 全局固定，保证可复现 |
