## 0. 使用规则

> **本清单是项目内所有数字的唯一真源。**

1. 论文、README、首页、报告、答辩稿引用数字时**必须**能对应到本清单的条目编号（`D-xx` / `S-xx` / `M-xx` / `E-xx`）；
2. 未经本清单标注的数字**禁止**出现在任何对外材料中；
3. 任何重训或数据更新后，**先更新本清单，再同步其他载体**；
4. 标注「不得改动」的条目，其变更必须先走 ADR。
