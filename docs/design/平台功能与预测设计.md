# 预警平台 · 功能、预测与 UI 设计方案

> 适用对象：Streamlit 前端 + FastAPI 后端的整体改造（本文覆盖功能/预测/UI；API 契约见 [`FastAPI服务层设计.md`](./FastAPI服务层设计.md)）。
> 状态：2026-11-14。标注「✅ 已实现」「🔧 待实现」「⚠️ 现有缺陷」。

---

## 1. 定位与用户场景

| 用户 | 场景 | 核心诉求 |
|---|---|---|
| 风控/信贷人员 | 每月对持仓或授信名单批量体检 | 快速打分、可解释、可导出、阈值可调 |
| 研究员/学生 | 复现论文、单企业归因 | 证据链、图表、报告 |
| 答辩评委 | 演示系统 | 一键就绪、口径自洽、可审计 |

三条设计原则：**决策优先**（先给结论再给解释）、**口径自洽**（T 年特征 → T+2 年 ST 风险，全站一致）、**可审计**（每个分数可追溯到 run_id、阈值来源、SHAP 归因）。

## 2. 信息架构

```text
平台首页（就绪体检 + 导航 + 关键口径）
├── 📊 数据看板     全市场态势 / 行业 / 趋势 / 排行 / 宏观 / 数据质量
├── 🏢 企业诊断     风险卡 / 六维雷达 / SHAP 瀑布 / 历史轨迹 / 核心指标
├── 📋 批量预警     代码/CSV 输入 → 评分 → 分级 → 导出
├── 🔍 模型解释     全局重要性 / 依赖 / 交互 / 五模型对比 / 漂移监控
└── 📄 报告导出     单企业 PDF / 批量 Excel / 评估报告
（建议新增）🛠️ 预警工作台  阈值、Top-K 预算、预警规则、处置状态流转
```

全局侧栏建议统一：**评分年度**、**行业过滤**、**阈值（高/中）**、**模型版本（run_id）**。

## 4. 预测功能设计（核心）

### 4.1 预测语义（必须全站统一）

- **特征年 T** 的财务/治理/文本/行情/宏观数据 → 输出 **T+2 年被实施 ST/*ST 的风险概率**。
- 因此「2023 年预测」真实含义是「预测 2025 年 ST 风险」，界面必须写清，禁止暗示为当年风险。
- 训练 2015–2021、验证 2022、测试 2023、锁箱 2024；任何 2024/2026 都不出指标。

### 4.2 推理模式

| 模式 | 输入 | 流程 | 适用 |
|---|---|---|---|
| A. 全量面板打分 | 无（feature_store） | `predict_frame(panel)` → 写 `cache/predictions.parquet` | 看板、排行、批量 |
| B. 按代码打分 | `stock_code` + 可选年度 | 面板子集 → 打分 | 企业诊断、批量 |
| C. 单企业 what-if（**缺失**） | 用户手工填 30+ 原始字段 | 原始字段 → 特征计算 → 打分 + 覆盖告警 | 新客户、尽调、压力测试 |

> 模式 C 是当前最大功能缺口：平台只能对**已入库公司-年**打分，无法对新企业或未来年份做预测。设计上复用 `etl.feature_engineering` 的单行特征函数 + 三级缺失兜底，输出时附 `coverage` 与 `imputed_features` 列表。

### 4.3 预测契约（JSON，与 FastAPI 对齐）

```jsonc
// 请求 POST /predict/codes
{ "codes": ["000004"], "year": 2023, "threshold_override": null }

// 响应
{
  "run_id": "20261114-213525-da08d92c",
  "semantics": "特征年 T → 标签年 T+2",
  "items": [{
    "stock_code": "000004", "company_name": "国农科技", "industry": "C27",
    "year": 2023, "st_prob_raw": 0.045, "st_prob": 0.0065,
    "risk_level": "低风险", "risk_percentile": 0.604,
    "thresholds": {"high": 0.0525, "medium": 0.0262},
    "top_features": [{"feature": "interest_debt_ratio", "shap": 0.13, "direction": "推高风险"}]
  }]
}
```

### 4.4 阈值与分级

- 概率经 isotonic 校准；阈值在验证集按 **FN:FP=10:1** 成本最小化冻结（当前 0.0525/0.0262）。
- 分级：`高风险 ≥ high`、`中风险 ≥ medium`、其余低风险；阈值可运行时覆盖（不改模型）。
- 新增 Top-K 预算视图：给定人工复核容量 N，直接给出「复核前 N 家」名单与命中率。

### 4.5 一致性与缓存

已实现三层一致性（见 `models/predict.py` / `models/shap_analysis.py`）：
1. 评分缓存 `predictions.parquet` 校验 `run_id` 与特征齐全，不一致自动重算；
2. SHAP 缓存校验 `run_id` + 特征数，不一致自动重算；
3. 预测概率与 SHAP 端点均过校准器，二者一致（实测差值 0）。

### 4.6 缺失与失败矩阵

| 场景 | 行为 |
|---|---|
| 代码不在面板 | 返回 404（列表模式返回 `unmatched` 清单） |
| 特征缺失（新公司） | 行业×年度中位数兜底 + `coverage` 告警，不静默补 0 |
| 模型/校准器缺失 | 5xx + 明确提示运行命令 |
| 缓存过期 | 自动重算并写日志 |

### 4.7 性能预算

- 全量 22,814 行打分 < 3 s；单公司 < 100 ms；SHAP 单样本 < 50 ms。
- FastAPI 无状态、模型进程级加载一次（`lru_cache` / lifespan）。

## 5. UI 设计

### 5.1 设计 tokens（现状 `utils/styles.py`，建议外置为 config）

| Token | 值 | 用途 |
|---|---|---|
| 主色 | `#1f77b4` | 品牌/图表主色 |
| 高风险 | `#e11d48`（红） | 风险卡、柱状 |
| 中风险 | `#f59e0b`（橙） | 风险卡 |
| 低风险 | `#10b981`（绿） | 风险卡 |
| 中性 | `#64748b` / `#94a3b8` | 文字、提示条 |
| 卡片 | 白底 + 1px `#e6e8eb` + 左 4px 主色 + 8–12px 圆角 | KPI / 模块卡 |
| 字号 | h1 2rem / h2 1.5rem / 正文 0.9rem / caption 0.8rem | 中文「微软雅黑/苹方」 |

风险语义**禁止只用颜色**：风险等级必须同时有文字 + 颜色 + （可选）图标，满足色盲可读。

### 5.2 页面线框（关键三页）

```text
【首页】
[ 就绪体检 5 项状态 + run_id 一致性 ] [ 一键命令 ]
[ 样本规模 | 特征维度(80→36) | 验证PR-AUC | 测试R@10 ]
[ 五大模块卡片 ]
[ 特征体系表 | 系统状态/模型元信息 ]

【企业诊断】
侧栏：代码下拉 / 年度 / 阈值
[ 风险卡(等级+概率+分位) | 同侪排名 | 六维雷达 ]
[ SHAP 瀑布图(校准后) | 关键风险因子表 ]
[ 历史风险轨迹 ] [ 核心财务指标 ]

【批量预警】
侧栏：年度 / 高风险阈值 / 中风险阈值 / [恢复默认]
[ 粘贴代码 | 上传 CSV ]
[ KPI: 评分数/高风险/中风险/均值 ] [ 分布图 | 清单表 ]
[ 导出 Excel / CSV ]   （顶部常驻：特征年 T → T+2 口径提示）
```

### 5.3 组件规范

| 组件 | 规范 |
|---|---|
| KPI 卡 | 4–5 个/行，`delta` 用 `inverse` 表达"越高越差" |
| 风险卡 | `risk_card_html`，等级词 + 概率 + 一句解释 |
| 提示条 | `insight` 灰底，解释图表读法或口径 |
| 表格 | 金额/比率统一单位，`st_prob` 显示 `%`，`hide_index`，表头可排序 |
| 空态 | 数据缺失时给 `PIPELINE_HINT`，不白屏 |
| 错误态 | 捕获 `DataNotReady`/`ValueError`，给下一步动作 |
| 加载态 | `st.cache_data(show_spinner=...)` 已覆盖主取数 |

### 5.4 交互规范

- 阈值滑块改动**只重算分级**，不重算概率（明确提示）；
- 「恢复默认阈值」按钮一键回填模型冻结阈值；
- 年度与行业筛选在侧栏全局联动；
- 关键口径用 `st.caption` 常驻，例如「概率已校准；特征年 T 对应 T+2 年 ST」。

### 5.5 文案红线（现状多处违反）

- ❌ 不说「准确率」；✅ 说「召回率 / 校准概率 / 排序能力」。
- ❌ 「高风险 = 概率 ≥ 50%」；✅ 「高风险 = 概率 ≥ 冻结阈值 0.0525」。
- ❌ 「当期真实 ST」；✅ 「T+2 年实际 ST（标签，用于回溯）」。
- ❌ 「覆盖 9 大维度」；✅ 「10 大维度，80 维候选 / 36 维入选」。
