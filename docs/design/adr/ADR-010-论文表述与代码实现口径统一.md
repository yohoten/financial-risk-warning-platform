# ADR-010 · 论文表述与代码实现的口径统一

> | 元信息 | 值 |
> |---|---|
> | 状态 | 🟡 待决（依赖 ADR-007 先行） |
> | 日期 | 2026-11-19 |
> | 关联问题 | 《项目诊断与开发建议书》P-01 |
> | 影响面 | `docs/Attachment/论文_第1-4章.md`、`README.md`、`index.html`、`reports/`、答辩稿 |

## 1. 背景

本项目的数字散落在**五处载体**：

| 载体 | 位置 | 生成方式 |
|---|---|---|
| 论文正文 | `docs/Attachment/论文_第1-4章.md`、`论文_系统设计与实现.md` | 人工撰写 |
| 根 README | `README.md` 指标表 | 人工撰写 |
| 首页 | `index.html` 的 `HOMEPAGE-DATA` 块 | `scripts/build_homepage.py` **自动注入**（`--check` 可校验） |
| 报告 | `reports/` 导出的评估报告与 PDF | `models/evaluate.py` 自动生成 |
| 答辩稿 | 口头/PPT | 人工 |

目前只有首页一处有自动一致性校验（`build_homepage.py --check`，已接入 CI），其余四处靠人工同步。这导致 2026-11-14 之后的口径变更（如 PR-AUC 主指标替换 AUC、官方标签切换、扩展窗口 CV）需要在多处手工对齐，且**没有机制保证下次仍然对齐**。

同时，论文正文的方法学表述（尤其 `:189` 的缩尾口径）与代码实现存在实质冲突（见 ADR-007）。

## 2. 候选选项

| 选项 | 说明 | 结论 |
|---|---|---|
| A. 维持人工同步 | 现状 | ❌ 已发生多次口径漂移；无机制保障 |
| B. 全部数字从产物自动生成 | 论文与 README 都从 JSON 渲染 | ❌ 论文是散文体，全自动不现实 |
| C. **单一真源 + 人工撰写 + 自动校验**：产物为真源，人工文档只引用不复制，CI 校验一致性 | 见下 | ✅ **采纳** |
| D. 引入 Notion/Confluence 外部文档系统 | 协作友好 | ❌ 破坏离线交付与版本可追溯 |

## 3. 决策

**采用 C**，具体为三条规则：

### 3.1 唯一真源表

建立《证据冻结清单》（`docs/design/证据冻结清单.md`），作为所有数字的**唯一定义处**。清单中每项数字标注：数值、来源产物文件、生成命令、run_id、数据 SHA256。

### 3.2 人工文档只引用，不复制

论文与 README 引用数字时**必须**给出出处（如「见《证据冻结清单》D-07」），不得就地复述未标注来源的数字。任何被复述的数字，都必须在清单中有对应条目。

### 3.3 自动校验

- 已具备：`scripts/build_homepage.py --check`（首页数据块 vs `evaluation_metrics.json` + README）；
- **待补（P2）**：
  - `scripts/check_evidence_freeze.py`——校验《证据冻结清单》表格中的数值与 `models/artifacts/*.json` 实际值逐项一致；
  - `scripts/check_doc_links.py`——校验全仓 Markdown 相对链接可达；
  - 论文数字校验——从论文 md 中抽取表格数字，与冻结清单做模式比对（需人工确认一次正则边界）。

## 4. 论文表述与代码的一致性处置

针对 ADR-007 暴露的冲突，最终采用以下**二选一**：

| 选项 | 含义 | 适用条件 |
|---|---|---|
| **X-1 改代码** | 按 ADR-007 方案 A 实现无泄漏预处理，重跑并用新数字更新论文 | 首选。论文现有表述「按训练窗口估计分位点、避免测试集信息泄露」即可保留，且无需弱化结论 |
| **X-2 改论文** | 保持代码现状，把论文 `:189` 改为如实描述全面板估计，并加一段局限性说明 | 仅当重跑后发现指标大幅下降、不愿承担结论变更时采用 |

**建议 X-1**。理由：项目的核心方法学主张就是防前视偏差，「论文承认有一处已知泄漏」对可信度的伤害大于「指标微调」；且以当前样本结构，泄漏对指标的影响大概率在 AUC ±0.005 量级，结论方向不会改变。

## 5. 后果

**正面**：五处载体有一致性保障机制；口径变更从「靠记性」变为「靠 CI」。

**负面**：需要一次性梳理《证据冻结清单》（本轮已产出初稿）；CI 增加两个脚本依赖；论文中的数字需要在每次重训后复核。

**约束**：在 X-1 落地前，**禁止**在任何新文档中复述未经清单标注的指标数字。

## 6. 状态

🟡 待决。建议在 P1 阶段与 ADR-007 一起执行：先改代码并重跑 → 冻结新数字 → 同步论文与 README → CI 接入校验脚本。
