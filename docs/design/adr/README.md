## 状态语义

| 标记 | 含义 |
|---|---|
| ✅ 已采纳并已实现 | 决策已落地，代码与文档均反映该决策 |
| 🟡 待决 | 问题已识别、方案已给出，等待实施窗口 |
| 🟡 部分落地 | 决策方向已定，但仍有子项未完成（如 ADR-009 的 SQLAlchemy 抽象） |
| 🔄 被取代 | 决策已被新 ADR 取代，仅作历史留存 |

## 模板

新增 ADR 请复制以下结构（文件名：`ADR-NNN-主题短句.md`）：

```markdown
# ADR-NNN · <一句话主题>

> | 元信息 | 值 |
> |---|---|
> | 状态 | 🟡 待决 |
> | 日期 | YYYY-MM-DD |
> | 关联文档 | 《…》 |
> | 影响面 | … |

## 1. 背景
## 2. 候选选项
（表格：选项 / 说明 / 结论）
## 3. 决策
## 4. 后果（正面 / 负面 / 约束）
## 5. 状态
```
