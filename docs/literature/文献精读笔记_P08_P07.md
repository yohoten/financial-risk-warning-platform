## P08 · NLP 与深度学习端到端破产预测架构

### 1. 文献元信息

| 项 | 内容 |
|---|---|
| 作者 | Gianfranco Lombardo, Andrea Bertogalli, Sergio Consoli, Diego Reforgiato Recupero |
| 标题 | Natural Language Processing and Deep Learning for Bankruptcy Prediction: An End-to-End Architecture |
| 出处 | *IEEE Access*, Vol. 12, 2024, pp. 151075–… |
| DOI | 10.1109/ACCESS.2024.3476621 |
| 证据等级 | B（同行评议应用/实证） |
| 获取 | 开放获取（CC BY 4.0） |

### 2. 研究问题与动机

把企业破产预测建模为**二分类**（正类 = 未来一年高破产风险）。作者指出现有两个缺口：

1. 现有研究对年报文本的利用停留在**词典法 / 词频法**的固定特征工程，受**概念漂移（concept drift）**影响——管理层会用套话稀释、改写措辞以规避固定词典的识别，导致文本特征随时间的预测力衰减。
2. 缺乏一个能**同时**利用「会计时序数据 + 文本披露」、且面向真实场景的**端到端**架构。

核心主张：用 Transformer 的自注意力机制**数据驱动地**学习「哪些披露内容对预测有价值」，而不是人工预设章节/词典。

### 3. 数据与样本

- **6190 家**美国上市公司，**1999–2018** 年。
- 两类输入：① 18 个会计变量（每个取最近 3 年构成时序）；② 10-K 年报全文。
- 标签：未来一年是否破产。
- 时间切分（关键）：训练 / 验证 / 测试按时间切（验证集 2012–2014），**避免随机切分泄漏未来信息**。

### 4. 方法/架构（端到端双模块）

```
10-K 年报 ──▶ 抽取式文本摘要 ──▶ DistilBERT 文档嵌入(768) ──┐
                                                          ├──▶ 拼接 ──▶ 微调 ──▶ 破产概率
18 会计变量(3年时序) ──▶ 多头 LSTM(每变量一个 head) ─────────┘
```

文本模块的三步「抽取式摘要」是本文最可迁移的方法学贡献：

1. **主题选择（Topic Selection）**：用 BoW 与 Loughran–McDonald 词典两种编码分别训练 Logistic，找出对破产判别最有价值的 10-K 章节——结论是 **Item 1（业务描述）、Item 5（市场趋势）、Item 7（管理层讨论 MD&A）**最有效；整个文档仅用词典法平均准确率约 **65%**。
2. **文档差分（Document Subtraction）**：利用年报年际高度相似（约 **90%** 复制粘贴），只保留相对上年**新增/修改/删除**的内容，聚焦「增量信息」。
3. **情感过滤（Sentiment Analysis）**：用 FinBERT 将每个 256-token 分块分类为 {正/中/负}，**丢弃中性块**（中性内容多为叙述性套话，信息量低）。

会计模块：**多头 LSTM**，18 个会计变量各配一个 LSTM head，输入为最近 3 年的时序。

两模块先各自独立训练，再拼接为单一模型做端到端微调。

### 5. 关键结果（数字已回查原文摘要与结论）

| 模块/组合 | 准确率 |
|---|---|
| 会计时序模块（多头 LSTM）单独 | **78%** |
| 文本披露模块（Transformer）单独 | **81%** |
| 端到端联合模型 | **87.5%** |
| 违约事件召回率 Recall | **0.84** |
| 第二类错误（漏报）Type II error | **16.12%** |

**读法**：文本模块（81%）单独已高于会计模块（78%），联合（87.5%）再提升约 6.5 个百分点——这是「文本对财务有增量」的**最强同行证据之一**，且是在时间切分（非随机）下得到的，比大量随机划分的同类研究更可信。

### 6. 主要贡献

1. 首个「抽取式摘要 → 文档嵌入 → 与会计时序端到端联合」的破产预测架构；
2. 对长文档（10-K 平均 2 万—4 万词）的摘要管线，解决 Transformer 512 token 长度限制；
3. 时间切分 + 概念漂移意识（continuous adaptation）；
4. 单模块消融分析（会计 vs 文本 vs 联合），方法上可复现。

### 7. 局限与不足

- 只报**准确率 / 召回率 / II 类错误**，**未报告 AUC、PR-AUC、校准（Brier/ECE）**——在强不平衡任务上准确率最不可比（本项目 P29 同样有此教训）。
- 验证集做了「随机平衡」（randomly balanced），虽只用于选超参，但会改变先验，需注意与测试集的概率口径差异。
- 依赖英文 SEC 10-K 结构化章节；中文 A 股年报无 Item 1/5/7 的规整结构，**章节对齐需重设计**。
- 端到端 Transformer 微调计算成本高、**可解释性弱**（无法像 SHAP 那样做特征级归因）。

### 8. 对本项目的直接启示

| 可借鉴 | 如何落地 | 风险 |
|---|---|---|
| 「文本有增量」的强证据 | 支撑未来「MD&A 文本特征」立项；引 P08 的 81%→87.5% | 美国英文文本，不能直接外推到 A 股 |
| 主题选择（用 IV/判别力选章节） | 用中文年报的「经营情况讨论与分析（MD&A）」作为主章节，先词典/FinBERT 打分 | 需先获得 MD&A 文本 |
| 文档差分（yoy 增量信息） | 用连续两年年报文本差异做「披露变化」特征 | 需要多年文本对齐，工程量大 |
| 时间切分 + 概念漂移 | 强化本项目「按年 CV + PSI 监控」的方法正当性 | — |

**不可直接套用**：① 87.5% 准确率不可作为本项目目标（任务、市场、标签、指标均不同）；② 端到端 Transformer 与「可解释性」核心主张冲突，本项目应以 SHAP 可解释树模型为主线。

## P07 · 消费信贷风险的可解释机器学习模型

### 1. 文献元信息

| 项 | 内容 |
|---|---|
| 作者 | Randall Davis, Andrew W. Lo, Sudhanshu Mishra, Arash Nourian, Manish Singh, Nicholas Wu, Ruixun Zhang |
| 标题 | Explainable Machine Learning Models of Consumer Credit Risk |
| 出处 | SSRN 工作论文（MIT Laboratory for Financial Engineering），2022-01-12 |
| SSRN | 4006840（本地为工作论文版本，非终版） |
| 证据等级 | B（工作论文，方法可参考、数字需谨慎） |

### 2. 研究问题与动机

在**真实数据集**上构建消费信贷风险（房屋净值信贷 HELOC）预测模型，并针对**四类利益相关者**提供差异化的可解释输出，以回应监管合规（美国 FCRA「必须披露影响信用的 4 个关键因素」、欧盟 GDPR「解释权」）。

核心问题不是「如何做得更准」，而是**「同一个黑箱模型，如何向不同的人解释」**。

### 3. 数据与样本

- FICO 公开的 HELOC 数据集（Fair Isaac Corporation）。
- 报告 §2.1 已回查：**10,459 名借款人**。
- 任务：房屋净值信贷违约二分类。

### 4. 方法：分层可解释性（按利益相关者）

| 利益相关者 | 需求 | 提供的解释工具 |
|---|---|---|
| **贷款机构** | 每次授信决策的理由 | LIME + SHAP 对**每个预测**生成归因 |
| **监管者** | 极端场景下的行为、公平性 | **压力测试**（stress test）方法学 |
| **贷款申请人** | 「我怎么做才能获批」 | 带领域约束的**反事实（counterfactual）**建议 |
| **数据科学家** | 理解数据结构与关系 | 归纳逻辑编程（ILP）提取的**简单规则** |

关键设计：作者**修改了 LIME** 以融入数据的约束（如 HELOC 特征的取值范围），使解释在业务上可用；反事实建议**加入了领域知识约束**（如「降低信用利用率」这类可执行动作），对 **99%** 的测试集个体成功生成了建议。

### 5. 关键结果（数字已回查摘要）

| 结果 | 数值 |
|---|---|
| 神经网络准确率（最优黑箱） | **74.75%** |
| 简单规则可解释的数据占比 | **70–72%**（1 条规则 70%，2 条规则 72%） |
| 反事实建议成功率 | **99%**（测试集个体） |

**读法**：作者刻意强调——**黑箱模型（NN）准确率最高（74.75%），但简单规则（ILP）已能解释 70–72% 的数据**。即「可解释性」与「性能」的差距在这个任务上并不悬殊，这为「用可解释模型/规则作为主模型」提供了论据。

### 6. 主要贡献

1. 提出「**按利益相关者分层解释**」的框架（机构/监管/申请人/数据科学家），是可解释 AI 落地信用领域的范式性工作；
2. 把 LIME/反事实与**领域约束**结合，使解释「可执行」而非「好看」；
3. 用 ILP 证明简单规则即可覆盖七成数据，支持「可解释优先」的工程决策。

### 7. 局限与不足

- 任务是**消费信贷**（个人 HELOC），不是上市公司 ST/财务困境——不能直接迁移结论；
- 本地为**工作论文**（2022-01），非终审版本，关键数字引用时需标注版本；
- 只报准确率，未系统报告 AUC/KS/校准；「74.75% vs 70–72%」的对比也隐含「规则模型已足够」的判断，需结合业务成本取舍。

### 8. 对本项目的直接启示

| 可借鉴 | 落地映射 | 优先级 |
|---|---|---|
| 分层解释框架 | 本项目「看板（全局）—诊断（单企业归因）—批量预警（排序）—报告导出」正是不同角色的解释产品 | ✅ 已有，可显式对齐 P07 术语 |
| 反事实建议 | 诊断模块的 SHAP 瀑布图可扩展为「降低哪些指标能降低风险分」的可执行建议 | P2 |
| 领域约束注入解释 | 特征方向（`higher_better`）+ 风险分级阈值，避免生成不可行的反事实 | P2 |
| 简单规则兜底 | 用 ILP/单棵树抽 2–3 条规则，验证「可解释模型即可解释大部分样本」，作为 SHAP 之外的「可解释锚点」 | P2 |

**不可直接套用**：P07 的「NN 最优」结论针对消费信贷，**不构成对本项目「树模型为主」的反驳**；其「规则模型已足够」的隐含判断也需结合本项目 3.4% 基础率与成本函数重新评估。
