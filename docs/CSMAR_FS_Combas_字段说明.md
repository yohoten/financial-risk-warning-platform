# CSMAR 合并资产负债表（FS_Combas）字段说明

> **数据来源**：国泰安 CSMAR 数据库  
> **验证基准**：贵州茅台（600519）2024年年度报告（2024-12-31）合并资产负债表  
> **最后更新**：2026-11-17  
> **免责声明**：本文档基于公开数据与CSMAR标准字段整理，实际字段可能因数据库版本、会计准则变更而有所差异，请以CSMAR官方数据字典为准。

---

## 1. 字段编码规则说明

CSMAR FS_Combas 采用层级编码体系：

| 编码前缀 | 含义 | 说明 |
|----------|------|------|
| A001 | 流动资产 | A0011xx = 流动资产明细科目 |
| A002 | 负债 | A0021xx = 流动负债，A0022xx = 非流动负债 |
| A003 | 所有者权益 | A0031xx = 归属于母公司权益，A0032xx = 少数股东权益 |

编码结构为 `A` + 3位大类 + 3位明细，共10位。例如 `A001101000` 表示"流动资产-货币资金"。

---

## 2. 数据单位与缺失值说明

- **金额单位**：所有数值字段单位为 **人民币元（CNY）**，非万元、非亿元。
- **缺失值**：空值/NULL 表示该公司当期无此项目或未披露，**不等于零**。
- **报表类型**：通过 `Typrep` 字段区分年报(A)、半年报(B)、一季报(C)、三季报(D)。
- **合并/母公司**：通过 `Ifmerge` 字段区分，Y=合并报表，N=母公司报表。

## 3. 会计准则变更提示 ⚠️

| 时间节点 | 变更内容 | 影响字段 |
|----------|----------|----------|
| 2019年起 | 新金融工具准则实施 | "可供出售金融资产"(A001201000)、"持有至到期投资"(A001202000) 被取消，替换为"债权投资"、"其他债权投资"、"其他权益工具投资"等新科目 |
| 2020年起 | 新收入准则全面实施 | "预收款项"部分转入"合同负债"；"应收利息""应收股利"可能并入"其他应收款" |
| 2021年起 | 新租赁准则实施 | 新增"使用权资产"、"租赁负债"等科目 |

> ⚠️ **高风险提示**：跨年度比较时，上述科目口径可能不一致，需注意会计准则切换导致的不可比性。

### 5.2 关键验证结论

1. **A001102000 = 交易性金融资产** ✅  
   此前有说法认为该字段可能是"应收票据"，经茅台年报验证确认：**A001102000 对应的是"交易性金融资产"**，而非应收票据。应收票据对应的是 A001103000。

2. **A001106000（应收利息）和 A001107000（应收股利）的顺序** ✅  
   编码顺序正确：A001106000 = 应收利息，A001107000 = 应收股利。但需注意：在新会计准则下，多数公司已将这两个科目并入"其他应收款"中列报，因此在近年年报中可能不再单独出现。

3. **A001108000 = 其他应收款** ✅  
   注意不是 A001106000 或 A001107000。其他应收款是独立的一级科目。
