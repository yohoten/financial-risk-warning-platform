## 四、写作规范速查

- **参考文献格式**：中文按 GB/T 7714-2015，英文按 APA 7th；
- **图表编号**：图 X-Y / 表 X-Y，图注在下、表注在上；
- **术语统一**：ST/*ST、财务困境（financial distress）、可解释性（XAI）、SHAP 值（log-odds 贡献）；
- **数字口径**：AUC/KS 保留 4 位小数，概率保留 2 位百分数，金额统一亿元。

## 五、维护约定

1. 新增文档请同时更新本索引与根 README 的"文档索引"表；
2. 设计变更时优先更新《系统架构设计说明书》的对应章节，再同步代码；
3. 所有 `.md` 使用 UTF-8 编码，Mermaid 图保持可渲染（GitHub / Typora / VS Code 均可）。
