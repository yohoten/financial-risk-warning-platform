## 📌 文档状态约定

| 标记 | 语义 | 读者应如何对待 |
|---|---|---|
| ✅ **已实现** | 与当前代码事实一致 | **可直接依赖** |
| 📝 **设计稿** | 方案已定稿，实现已完成或待补验收记录 | 读作「意图」，具体行为以代码为准 |
| 📊 **分析结论** | 某一時点��诊断/评估结论 | **可能已被后续修复超越**，引用前核对状态说明 |
| 🔄 **被取代** | 已被更新口径取代 | **仅作历史留存**，禁止引用其数据与结论 |
| ⛔ **已废止** | 结论或路径已失效 | **禁止引用**，保留仅为追溯 |
| 🟡 **待决** | 问题已识别、方案已给出 | 按 ADR 标注的阶段执行 |

**取代关系规则**：本文档取代他人 → 在「取代关系」写明被取代者；被他人取代 → 自身状态改 🔄 并指向新文档。**不删除有引用价值的历史文档**。

完整规范见 [《文档编写规范》](./design/文档编写规范.md)。
