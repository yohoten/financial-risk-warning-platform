# 前端架构与图表方案（Streamlit 壳 + FastAPI 服务层 + Plotly/ECharts）

> 目标：把「展示、服务、图表」三层解耦，既能在答辩离线环境一键运行，又能服务化复用。
> 状态：2026-11-14。默认已落地；ECharts 为选配（放本地 `echarts.min.js` 后自动启用）。

---

## 1. 总体架构

```mermaid
flowchart LR
    subgraph 壳["展示层 Streamlit"]
        P1[六模块页面]
        B[utils/backend.py<br/>统一取数入口]
        C{图表引擎}
    end
    subgraph 服务["服务层 FastAPI api/"]
        A1[/predict/* /explain/*<br/>/model/* /monitor/*]

        M1[models.predict]

    end
    subgraph 图表["图表层"]
        PL[Plotly · 默认]
        EC[ECharts · 选配本地化]
    end

    B -->|RISK_API_URL 设置| A1
    B -->|未设置/失败回退| M1
    A1 --> M1
    B --> C
    C --> PL
    C --> EC
```

三层职责：

| 层 | 组件 | 职责 | 是否可离线 |
|---|---|---|---|
| 展示层 | `streamlit_app/*` | 交互、布局、状态、导出 | ✅ |
| 服务层 | `api/*`（FastAPI） | 评分/解释/监控 HTTP 接口、输入校验、异常映射 | ✅ |
| 图表层 | Plotly（默认）+ ECharts（选配） | 可视化渲染 | Plotly ✅ / ECharts ✅（本地 vendor） |
| 领域层 | `models/*` | 业务逻辑唯一实现，服务层与本地直连共用 | ✅ |

## 2. Streamlit 壳设计

- **页面结构不变**（六大模块），只把数据访问收敛到 `utils/backend.py`，页面不再直接 import `models.*`。
- **双后端透明切换**：`RISK_API_URL` 未设置 → 本地直连；已设置 → HTTP，失败自动回退本地。
  - 回退保证答辩演示不因后端未启动而白屏。
- **全局状态约定**：侧栏统一放「年度 / 行业 / 阈值 / 模型版本 run_id」。
- **口径常驻**：特征年 T → 标签年 T+2、概率已校准、阈值来源，用 `caption` 固定展示。

统一入口签名（与现有 `utils/data.py` 对齐，页面迁移成本低）：

```python
# streamlit_app/utils/backend.py
mode()                          # 'api' | 'local'
get_predictions() -> DataFrame   # 全量评分
predict_codes(codes, year) -> DataFrame
local_contribution(code, year) -> dict
global_importance(top_n) -> DataFrame
health() -> dict
```

## 4. 图表层：Plotly 为主 + ECharts 选配本地化

### 4.1 分工原则

| 图 | 引擎 | 理由 |
|---|---|---|
| SHAP 瀑布 / 依赖 / 交互 | **Plotly** | `shap` 原生输出 Plotly 对象，零翻译成本 |
| 风险雷达 / 校准曲线 / PSI / 五模型对比 | **Plotly** | 已实现且中文/交互满足 |
| 行业×年度热力 / ST 趋势 / 行业风险柱 | **Plotly 默认，ECharts 可选** | ECharts 视觉上限更高、大数据更流畅 |
| 风险桑基 / 特征→风险流向 / 区域地图 | **ECharts（P1 扩展）** | Plotly 桑基/地图较弱 |

### 4.2 ECharts 本地化（关键）

`streamlit-echarts` 默认从 CDN 加载 echarts.js，**离线答辩会白屏**，因此本项目自建
无构建自定义组件：

```text
streamlit_app/components/echarts_local/
├── index.html          # 本地 <script src="./echarts.min.js">，无 CDN
├── echarts.min.js      # 需自行放入（固定 5.5.1，约 1 MB）
└── README.md           # 下载指引
```

Python 侧（`utils/echarts_options.py`）：

```python
E.has_echarts()                      # echarts.min.js 是否存在
E.render_echarts(option, height, key)  # 渲染；缺失时 caption 提示
E.industry_year_heatmap_option(scored) # 数据 → option 纯函数
E.st_trend_option(scored)
E.industry_risk_bar_option(latest)
```

- **未放入 echarts.min.js 时**：`has_echarts()` 为 False，看板不显示切换开关，全走 Plotly，
  现有行为完全不变。
- **放入后**：数据看板顶部出现「Plotly / ECharts」单选，切换即可对比。

### 4.3 颜色与主题统一

`echarts_options.py` 复用 `charts.py` 的 BLUE/RED/ORANGE/GREEN/GRAY 与 `RISK_COLORS`，
两套引擎视觉口径一致。
